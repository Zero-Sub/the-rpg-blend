# Security and Sensitive Information

## Scope

This repository contains public technical writing, educational material, examples, frameworks, and brand assets. It must not be used to store credentials, private operational data, production details, or confidential organizational information.

## Do Not Open a Public Issue For

- Passwords, API keys, tokens, certificates, or connection strings
- Private hostnames, IP addresses, ports, user profiles, or network diagrams
- Customer, patient, employee, candidate, or vendor-confidential information
- Proprietary source code or production data without explicit authorization
- Screenshots that expose credentials, system identifiers, private paths, or client information
- Security weaknesses that could place a real system or organization at risk

## Reporting a Sensitive Problem

Do not post sensitive details in a public issue, discussion, pull request, or commit.

Contact George VanEaton through an established private The RPG Blend contact channel and provide only the minimum information needed to establish the nature of the problem. Additional details can be exchanged through an appropriate private method.

If no private contact channel is available, open a public issue containing only a request for private contact. Do not include the sensitive details.

## Public Technical Corrections

Non-sensitive corrections may be reported through the technical-correction issue template. Examples include:

- Incorrect RPG, CL, SQL, or IBM i syntax
- Broken repository links
- Outdated public documentation references
- Ambiguous educational instructions
- Inconsistent brand or terminology usage

## Supported Material

Security and correction support applies to the current default branch and the most recent published release. Older drafts, forks, local copies, and third-party adaptations may not receive corrections.

## Educational Disclaimer

Code, commands, configurations, and technical examples are provided for educational purposes. Review and test all material in an appropriate non-production environment before use.
