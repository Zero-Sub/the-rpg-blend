# The RPG Blend Site Strategy

## Purpose

The repository is the source of truth for The RPG Blend. The public site should become the durable archive and professional presentation layer.

## Channel Roles

| Channel | Role |
|---|---|
| GitHub | Source of truth, templates, standards, versioned content |
| GitHub Pages | Public archive and professional site |
| Substack | Email distribution and subscriber growth |
| LinkedIn | Visibility, discussion, and professional amplification |

## Recommended Initial Stack

Start simple.

Recommended options:

- Astro
- Next.js
- Minimal Jekyll

The priority is consistency and publishing discipline, not frontend complexity.

## Initial Requirements

- Responsive design
- Dark mode support
- SEO metadata
- RSS feed
- Article categorization
- Search
- Architecture-focused visual identity

## Content Categories

- IBM i Modernization
- RPG Architecture
- SQL Engineering
- AI Adoption
- Operational Excellence
- Engineering Leadership

## Long-Term Goal

Build a respected engineering publication and modernization reference library for enterprise IBM i organizations.
