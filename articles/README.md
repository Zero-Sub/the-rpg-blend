# Article Library

Approved long-form articles and cornerstone essays belong under a topic directory in `/articles`.

## Canonical Categories

### `ibmi-modernization`

Modernization strategy, architecture evolution, refactoring, service boundaries, and platform transformation.

### `rpg-architecture`

Free-form RPG, service programs, layered design, business-logic boundaries, and maintainability.

### `sql-engineering`

SQL standards, stored procedures, performance, views, indexing strategy, and operational SQL usage.

### `ai-assisted-development`

IBM Bob, prompting, AI-assisted reviews, governance, workflow integration, and engineering enablement.

### `operational-excellence`

Release management, deployment discipline, observability, production support, and predictable delivery.

### `engineering-leadership`

Technical leadership, organizational modernization, communication, talent development, risk management, and change leadership.

### `developer-education`

Developer onboarding, skills development, mentoring, structured learning, and professional growth.

### `production-support`

Troubleshooting, incident response, operational diagnostics, recovery, and long-lived system stewardship.

## File Standard

- Store each article as Markdown with a `.md` extension.
- Use lowercase kebab-case filenames.
- Place each article in the category that best represents its primary argument.
- Do not place article drafts or finished articles directly in the repository root.
- Avoid duplicate category directories for the same subject.
- Keep publication-channel adaptations under `/distribution`, not beside the canonical article.
