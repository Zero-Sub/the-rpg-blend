# Course Syllabus

## Course

**RPGBA-101 — Getting Started with IBM i Development—and Coffee**

## Course description

Module 0 introduces learners to IBM i, RPG, Db2 for i, the IBM i object model, modern development tooling, and the basic edit-compile-run workflow. It is designed as the first onboarding course for a future Associate RPG Developer.

## Target audience

- College graduates with basic programming knowledge
- Developers transferring from another platform
- Future Associate RPG Developers
- IBM i developers moving toward a modern VS Code-based workflow

## Prerequisites

Learners should be able to:

- understand variables, conditions, procedures, and basic program flow;
- navigate a modern desktop operating system;
- install approved software or work with an administrator who can;
- follow written technical instructions;
- use only approved nonproduction environments.

No prior RPG or IBM i experience is required.

## Learning objectives

By the end of this course, the learner can:

1. Explain what IBM i is and distinguish IBM i from historical platform names.
2. Explain the role of RPG and Db2 for i.
3. Distinguish libraries, objects, source physical files, source members, schemas, tables, and IFS paths.
4. Install Visual Studio Code, Code for IBM i, and approved Db2 for i tooling.
5. Connect to an approved IBM i training environment.
6. Verify the host, identity, library list, current library, and target location.
7. Open and explain a small free-form RPG program.
8. Make a controlled code change.
9. Compile the program and review diagnostic messages.
10. Run the program and record evidence.
11. Execute an introductory SQL activity.
12. Use IBM Bob for explanation or troubleshooting while validating its output.
13. Commit work using Git.
14. Complete an independent task without relying entirely on Bob.

## Estimated duration

Approximately **4 to 5 hours** for a true beginner, including installation, labs, troubleshooting, assessment, and feedback.

## Required software

- Visual Studio Code
- Code for IBM i
- Approved Db2 for i extension tooling
- Git
- IBM Bob when available for the pilot
- IBM i Access Client Solutions when required by the environment

## Required IBM i access

- Approved nonproduction IBM i host
- Assigned learner user profile
- Assigned library or schema
- Approved IFS training location when required
- SSH and compiler access appropriate to the labs

## Course activities

- Platform and terminology orientation
- Tool installation and configuration
- Safe connection and context verification
- Object and IFS navigation
- First RPG change, compile, and run
- Introductory Db2 for i SQL activity
- Bob-assisted explanation or troubleshooting
- Git commit and evidence submission
- Knowledge check and independent task

## Assessment

Completion is based on:

- knowledge check score of at least 80%;
- successful completion of the practical lab;
- successful completion of the independent task;
- accurate evidence submission;
- appropriate and validated use of IBM Bob;
- zero safety or security violations.

## Completion criteria

The learner must demonstrate that they can repeat the core workflow with reduced guidance, explain what they changed and compiled, identify where the resulting object was created, interpret basic messages, validate an AI-assisted answer, and commit the work through Git.
