# Pilot Instructions

## Recommended delivery format

Deliver the course in four sessions rather than forcing a true beginner through one long block.

| Session | Focus | Target time | Required evidence |
|---|---|---:|---|
| 1 | Academy orientation, IBM i concepts, and installation | 60–75 min | Installed tools and completed preflight |
| 2 | Connection, libraries, objects, source members, and IFS | 60 min | Context verification record |
| 3 | RPG source, compile, diagnostics, and run | 60–75 min | Compile and run evidence |
| 4 | Db2 for i, IBM Bob, Git, assessment, and independent task | 60–75 min | Commit, assessment, and feedback |

## Facilitator role

The facilitator should guide the learner without taking over the keyboard or solving every problem.

When a learner becomes stuck:

1. Wait long enough to observe the actual problem.
2. Ask the learner to describe what they expected.
3. Record the unclear instruction, label, or concept.
4. Provide the smallest hint needed to continue.
5. Record whether the issue was environmental, instructional, or learner-related.

## What to observe

- Installation steps that do not match the current interface
- Terms the learner cannot explain
- Incorrect assumptions about libraries, objects, members, schemas, or IFS paths
- Connection and authentication failures
- Wrong-host, wrong-profile, or wrong-library risks
- Compile errors and the learner's response to diagnostics
- Places where IBM Bob helps learning
- Places where IBM Bob creates confusion or overreliance
- Git workflow problems
- Safety, privacy, or credential-handling concerns

## Pilot success measures

- Every learner completes the safe connection and context check.
- Every learner compiles and runs the starter program.
- Every learner completes the introductory SQL activity.
- Every learner records one validated Bob-assisted result.
- Every learner completes the independent task.
- Knowledge-check score is at least 80%.
- No credentials, PHI, customer data, or production records are exposed.
- Every significant course defect is recorded.

## Feedback

Use the repository's **RPGBA-101 Module 0 Pilot Feedback** issue template. Feedback should identify:

- the section or file;
- the exact point of confusion;
- expected versus actual behavior;
- screenshots with sensitive information removed;
- whether the learner could continue;
- the suggested correction when known.
