# RPGBA-101 Module 0 Pilot

## Getting Started with IBM i Development—and Coffee

This is the learner-facing pilot release for college graduates and developers preparing for an Associate RPG Developer path.

**The RPG Blend Academy is the education division of The RPG Blend.** It provides practical IBM i developer training focused on modern tools, enterprise safety, responsible AI use, and real-world engineering skills.

## Start here

1. Read [Start Here](START-HERE.md).
2. Review [About The RPG Blend Academy](ABOUT-THE-ACADEMY.md).
3. Review the [Course Syllabus](COURSE-SYLLABUS.md).
4. Follow the [Pilot Instructions](PILOT-INSTRUCTIONS.md).
5. Use the current course source and code under [`../../curriculum/level-000/module-00/`](../../curriculum/level-000/module-00/).
6. Submit feedback using the repository's Module 0 pilot feedback issue template.

## What learners will do

- Install Visual Studio Code and approved IBM i extensions.
- Connect to an approved nonproduction IBM i environment.
- Navigate libraries, objects, source members, and IFS paths.
- Read, change, compile, and run a small RPG program.
- Execute an introductory Db2 for i SQL activity.
- Use IBM Bob responsibly and validate its output.
- Commit work with Git and submit evidence.

## Package status

This public repository contains editable course source, code, labs, prompts, and release history. Controlled binary artifacts such as the final branded PowerPoint and DOCX course package are maintained separately until GitHub Release assets are published.

## Safety boundary

Use only an approved nonproduction IBM i environment. Never place passwords, private keys, PHI, customer data, production records, access tokens, or confidential system details in Git, screenshots, course notes, or AI prompts.

## Pilot status

Release candidate for structured learner testing. It is not yet the final public v1.0 course.
