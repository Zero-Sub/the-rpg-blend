# Start Here

Welcome to RPGBA-101 Module 0: **Getting Started with IBM i Development—and Coffee**.

Module 0 is the Academy onboarding module. It is designed for learners who understand basic programming concepts but may be new to IBM i, RPG, Db2 for i, and enterprise IBM i development practices.

## What this review candidate is testing

The review is testing whether the course can teach a capable new developer to:

- understand the IBM i platform at a practical level;
- choose and use the appropriate modern IBM i development tool;
- connect safely to a training environment and verify context;
- navigate libraries, objects, source members, and the IFS;
- make, compile, run, and explain a small RPG change;
- complete an introductory Db2 for i SQL activity;
- use IBM Bob responsibly and validate its output;
- record evidence and work through Git;
- complete an independent task without relying on Bob for the core change or explanation.

## Expected time

Plan approximately **5 to 7 hours** for guided labs, knowledge checks, evidence capture, and the independent task. The material may be delivered as one extended session or split across multiple sessions. A shortened demonstration is not equivalent to learner completion.

A practical split is:

1. Academy orientation, IBM i concepts, tool selection, installation, and verification.
2. Connection, libraries, objects, source members, IFS, and authority boundaries.
3. RPG source, compile, diagnostics, run, and evidence.
4. Db2 for i, Bob-integrated review, Git, assessment, and the independent task.

## Primary toolbelt

- Visual Studio Code
- Code for IBM i
- Db2 for i extension
- Git
- IBM Bob when available
- IBM i Access Client Solutions when appropriate for Run SQL Scripts, 5250, spooled files, IFS/data transfer, database tooling, or SQL performance work
- IBM Navigator for i for approved browser-based system, security, work-management, and administrative views

Learners should also recognize SEU, PDM, STRSQL, RDi, and other existing workflows so they can support real IBM i environments while using the Academy's modern VS Code-first approach where practical.

## Before you begin

Confirm the assigned nonproduction host, learner profile, library/schema, IFS path when required, VS Code installation permission, Git, approved extensions, and IBM Bob access when included.

## How to work

- Verify context before making a change.
- Predict the result before compiling or running.
- Make the smallest controlled change.
- Read diagnostics and runtime evidence.
- Validate Bob output before accepting it.
- Inspect the Git diff before committing.
- Explain the work in your own words.
- Stop and escalate when the target, data boundary, or authority is unclear.

## Completion standard

You complete Module 0 when you can verify context, select the right tool, connect through Code for IBM i, explain and modify the starter RPG program, compile and interpret basic diagnostics, run the intended program, complete the SQL activity, validate one Bob-assisted result, inspect/commit your Git work, and complete the independent task and assessment.

Deeper RPG language development begins in **Module 1: RPG Fundamentals — Read, Change, Test — and Coffee**.
