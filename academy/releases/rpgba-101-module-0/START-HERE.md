# Start Here

Welcome to RPGBA-101 Module 0: **Getting Started with IBM i Development—and Coffee**.

This course is the first step in The RPG Blend Academy learning path. It is designed for learners who understand basic programming concepts but may be completely new to IBM i, RPG, Db2 for i, and enterprise IBM i development practices.

## What this pilot is testing

The pilot is not testing whether you already know IBM i. It is testing whether the course can teach a capable new developer to:

- understand the IBM i platform at a practical level;
- install and use modern IBM i development tools;
- connect safely to a training environment;
- make, compile, run, and explain a small RPG change;
- use SQL and IBM Bob responsibly;
- record evidence and work through Git.

## Expected time

Plan for approximately **4 to 5 hours**, ideally delivered in four sessions:

1. Platform orientation and installation — 60 to 75 minutes
2. Connection, libraries, objects, source members, and IFS — 60 minutes
3. RPG source, compile, diagnostics, and run — 60 to 75 minutes
4. Db2 for i, IBM Bob, Git, assessment, and independent task — 60 to 75 minutes

## Before you begin

Confirm that you have:

- an approved nonproduction IBM i host;
- an assigned learner profile;
- an assigned library or schema;
- an approved IFS training path when required;
- Visual Studio Code installation permission;
- Git installed;
- access to Code for IBM i and Db2 for i extensions;
- IBM Bob access when included in the pilot.

## How to work

- Try each instruction before asking for help.
- When stuck for five minutes, record exactly what is confusing.
- Do not hide mistakes; they help improve the course.
- Never expose credentials, PHI, customer data, production records, or confidential system information.
- Explain what you did in your own words.
- Validate IBM Bob output before accepting it.

## Completion standard

You complete Module 0 when you can:

- verify the host, identity, library, and target context;
- connect through Code for IBM i;
- explain the starter RPG program;
- make a controlled change;
- compile and interpret basic diagnostics;
- run the program;
- complete the SQL activity;
- use and validate one Bob-assisted result;
- commit your work to Git;
- complete the independent task and assessment.
