# The RPG Blend Academy Assessment Standard

## Purpose

Assessments verify that students can explain, recognize, apply, troubleshoot, and review the skills taught by the Academy. They are evidence of learning, not trivia collections.

## Assessment Types

- Lesson knowledge check
- Module quiz
- Practical lab assessment
- Code review exercise
- Troubleshooting scenario
- Module capstone
- Instructor observation

## Alignment Rule

Every assessment item must map to a published learning objective. Do not test content that was not taught or identified as a prerequisite.

## Cognitive Mix

Each module assessment should include a balanced mix of:

- Recall: identify terms, syntax, and definitions
- Interpretation: explain what code or SQL does
- Application: choose or write an implementation
- Troubleshooting: diagnose a compile, runtime, data, or logic problem
- Judgment: compare approaches and explain production tradeoffs

## Question Standards

### Multiple Choice

- Use one clearly best answer
- Avoid trick wording
- Make distractors plausible
- Do not use grammatical clues
- Avoid “all of the above” unless essential

### Short Answer

- State the expected scope
- Provide a scoring rubric
- Accept technically equivalent wording

### Code Reading

- Use complete and readable examples
- Ask about behavior, output, side effects, or defects
- Identify release assumptions when relevant

### Practical Tasks

- Provide business context and acceptance criteria
- Assess working behavior and code quality
- Require evidence such as output, query results, or test results

## Required Lesson Knowledge Check

Each lesson includes five to ten questions covering at least three cognitive levels. The answer key must explain why the correct answer is correct and, for multiple choice, why the strongest distractors are wrong.

## Module Assessment Model

Recommended weighting:

| Component | Weight |
|---|---:|
| Knowledge and terminology | 20% |
| Code and SQL reading | 20% |
| Hands-on implementation | 40% |
| Troubleshooting and professional judgment | 20% |

Weights may change by module, but practical work should remain the largest component after Level 000.

## Scoring Levels

| Result | Meaning |
|---|---|
| Not Yet Demonstrated | Cannot complete the task without substantial intervention |
| Developing | Completes portions with frequent guidance |
| Proficient | Completes the task safely with normal review |
| Advanced | Completes the task independently and explains tradeoffs |

## Passing Standard

A student should not pass solely through quiz performance. Passing requires:

- At least 80% on knowledge checks unless a module specifies otherwise
- Successful completion of required labs
- No critical safety or data-integrity failure in the practical assessment
- Demonstrated ability to explain the submitted solution

## Critical Failure Conditions

The following require correction regardless of numeric score:

- Exposing credentials or sensitive data
- Running destructive work outside the training environment
- Ignoring required error handling
- Introducing an unresolved data-integrity defect
- Submitting code the student cannot explain
- Using AI-generated output without required review and validation

## AI Use in Assessments

Each assessment must state one of these modes:

- AI prohibited
- AI allowed for reference only
- AI allowed with prompt and output disclosure
- AI encouraged as part of the assessed workflow

When AI is allowed, students remain accountable for correctness, security, testing, and explanation.

## Answer Key Requirements

Instructor answer keys include:

- Correct answer or expected behavior
- Explanation
- Objective mapping
- Point value
- Partial-credit guidance
- Common misconceptions
- Acceptable alternate solutions

## Assessment Review

Before release, assessments must be checked for:

- Objective alignment
- Technical accuracy
- Ambiguous wording
- Appropriate difficulty
- Coverage balance
- Answer-key completeness
- Student completion time
- Accessibility and readability

## Definition of Done

An assessment is complete when the student version, instructor key, rubric, objective map, passing criteria, AI-use mode, and validation evidence are committed and reviewed.
