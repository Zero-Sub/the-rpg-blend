# Coffee Company — Module 1 Source

This folder contains the Module 1 RPG Foundations state of the Academy Coffee Company reference application.

- `COFFEE01.rpgle` — evolved RPG pricing slice used for Module 1 learning and validation.

The source intentionally stays small. Module 1 teaches RPG foundations, not Db2 access, service-program design, APIs, or a full MVC implementation.

Starting baseline comes from Module 0:

`academy/curriculum/level-000/module-00/code/rpg/COFFEE00.rpgle`

The Module 1 ending state should be treated as the RPG-side starting point for Module 2/3 integration after those modules' canonical contracts are locked.

Status: Release Candidate. Do not mark Final until live IBM i compile/runtime validation passes.
