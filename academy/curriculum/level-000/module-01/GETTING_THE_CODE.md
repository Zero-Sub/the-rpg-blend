# Module 1 — Getting the Coffee Company Code

The Coffee Company source used by Module 1 is stored in the Academy GitHub repository.

Repository: `Zero-Sub/the-rpg-blend`

Module 0 starter source:

`academy/curriculum/level-000/module-00/code/rpg/COFFEE00.rpgle`

Module 1 evolved source:

`academy/curriculum/level-000/module-01/src/coffee-company/COFFEE01.rpgle`

## Recommended learner workflow

1. Open Visual Studio Code.
2. Open a terminal in the folder where you keep Academy work.
3. Clone the repository if you do not already have it:

   `git clone https://github.com/Zero-Sub/the-rpg-blend.git`

4. Open the cloned `the-rpg-blend` folder in VS Code.
5. Navigate in Explorer to:

   `academy/curriculum/level-000/module-01/src/coffee-company`

6. Open `COFFEE01.rpgle`.
7. Do not edit `main` directly for Academy work. Create the learner branch required by the lab/instructor.
8. Verify the intended IBM i connection, profile, source location, learner library, and target object before compiling.

## If you already completed Module 0

Keep using the same repository clone. Run:

`git pull`

Then navigate to the Module 1 path above. Module 1 continues the Coffee Company application rather than starting a disconnected project.

## What the learner must be able to explain

- where the source came from;
- which repository path contains the current module source;
- which branch contains the learner's work;
- what is local Git source versus the compiled IBM i program object;
- how the Module 1 code continues the Module 0 Coffee Company baseline.
