# RPGBA-101 Module 0 Code Repository

This repository contains original starter code for RPGBA-101: Getting Started with IBM i Development-and Coffee.

## Training boundary

Use only the approved non-production IBM i environment, assigned profile, assigned library/schema, and approved IFS path. Never use production data or credentials in this repository or in AI prompts.

## Suggested workflow

1. Open this folder in VS Code.
2. Connect to IBM i with Code for IBM i.
3. Verify host, user, current library, and library list.
4. Review `src/rpgle/HELLO.rpgle`.
5. Compile using your approved site action or command.
6. Run the program and record evidence.

## Source notes

Examples are original Academy examples. IBM and COMMON materials were used only for terminology and coverage validation.
