# Module 0 — Getting the Coffee Company Code

The Coffee Company starter source is stored in the Academy GitHub repository.

Repository: `Zero-Sub/the-rpg-blend`

Starter RPG source:

`academy/curriculum/level-000/module-00/code/rpg/COFFEE00.rpgle`

Supporting CL utilities:

`academy/curriculum/level-000/module-00/code/cl/`

## First-time learner workflow

1. Install Git and Visual Studio Code as directed by Module 0 preflight.
2. Open a terminal in the folder where you want to keep Academy work.
3. Clone the repository:

   `git clone https://github.com/Zero-Sub/the-rpg-blend.git`

4. Open the cloned `the-rpg-blend` folder in VS Code.
5. In Explorer, navigate to:

   `academy/curriculum/level-000/module-00/code/rpg`

6. Open `COFFEE00.rpgle`.
7. Before compiling, verify the approved IBM i connection, profile, learner library, source location, and target object.
8. Follow the Module 0 lab rather than copying source into an arbitrary library or production location.

## Returning learner workflow

If the repository is already cloned:

1. Open the existing local `the-rpg-blend` folder.
2. Check your branch and working tree.
3. Preserve or commit learner work as instructed.
4. Update the repository safely with `git pull` when the course tells you to do so.
5. Navigate to the module path above.

## What is where

- GitHub / local clone: source and Academy course artifacts.
- IBM i source/workspace: the approved learner copy used for compile/run exercises.
- IBM i program object: the compiled executable object; it is not the same thing as the Git source file.

The learner must be able to explain those three locations before completing Module 0.
