# Lesson 0.6 — Do It Without Me

## Purpose

Prove learner independence before Module 1.

## Learning objectives

By the end, the learner can independently complete a small Coffee Company change using the approved course references, evidence standards, and troubleshooting process without step-by-step expert direction.

## Independent requirement

Change the Coffee Company orientation message to:

`Coffee Company Module 1 ready.`

Do not ask an instructor or AI assistant to supply the workflow before your first attempt.

Course references are allowed.

## Prove

Independently:

1. verify the approved connection, identity, source, learner library, and target;
2. locate the correct Coffee Company source;
3. write the expected result before editing;
4. make only the required change;
5. compile using the approved build path;
6. interpret any diagnostic rather than guessing;
7. verify the intended `COFFEE00 *PGM`;
8. run and compare expected vs actual;
9. inspect the Git diff/evidence;
10. record the result safely;
11. explain what you did without AI assistance.

AI may be used after your first independent attempt for explanation, diagnosis, review, or test ideas. You remain responsible for verification and the final decision.

## Troubleshooting ladder

When blocked:

1. Stop.
2. Restate the goal.
3. Verify host → profile → source → library → target.
4. Compare expected versus actual.
5. Read the diagnostic.
6. Use the course troubleshooting material.
7. Use approved AI assistance for explanation if useful.
8. Verify suggestions.
9. Escalate with evidence.

If you escalate, provide the instructor with the goal, expected result, actual result, diagnostic, context, and checks already performed.

## Review

The instructor records the highest intervention level required:

0. Independent
1. Clarification only
2. Hint
3. Step-by-step guidance
4. Instructor performed action

A completed workflow that required level 2–4 assistance is still valuable learner evidence, but it is also curriculum evidence that must be reviewed.

## Explain

Without AI assistance, answer:

- What did the source do before the change?
- What requirement changed?
- Which source did you edit?
- Where did it compile?
- What object did you run?
- What did the compiler prove?
- What did runtime evidence prove?
- What did Git prove?
- What did AI contribute, if used?
- What final decisions remained yours?

## Completion criteria

The learner is ready for Module 1 only when they can complete the core controlled-change workflow with no step-by-step expert direction, keep evidence internally consistent, stay within security/safety boundaries, and explain the result.
