# Curriculum Map

## Level 000 — Orientation

| Module | Title | Primary outcome |
|---|---|---|
| 0 | Getting Started with RPG (and Coffee) | Explain IBM i, RPG, platform naming, tools, and the basic program lifecycle |
| 1 | Navigating IBM i | Understand libraries, objects, jobs, queues, and common commands |
| 2 | Reading Your First RPG Program | Identify source sections, declarations, logic, and output |

## Level 100 — Associate RPG Developer Foundations

| Module | Title | Primary outcome |
|---|---|---|
| 100 | RPG Variables and Data Types | Declare and use common RPG data types safely |
| 110 | Decisions and Loops | Implement clear program flow and avoid common loop errors |
| 120 | Procedures and Program Structure | Organize logic into testable procedures |
| 130 | IBM i Database Foundations | Understand physical files, logical files, tables, rows, records, keys, and members |
| 140 | Native Record-Level Access | Use CHAIN, SETLL, READE, READ, WRITE, UPDATE, and DELETE |
| 150 | SQL Foundations | Query and modify data using SQL |
| 160 | Embedded SQL in RPG | Use host variables, cursors, diagnostics, and safe error handling |
| 170 | Display Files and 5250 Applications | Read and maintain basic interactive applications |
| 180 | Debugging and Production Support | Compile, debug, inspect jobs, read messages, and diagnose failures |
| 190 | Safe Change Delivery | Complete a supervised change using Git, review, testing, and deployment discipline |
| 199 | Associate Capstone | Deliver a small working feature in the sample application |

## Level 200 — Professional RPG Development

Planned topics include modular design, ILE, service programs, binding directories, SQL-first access, stored procedures, JSON, REST APIs, testing, performance, security, and advanced Git workflows.

## Level 300 — IBM i Modernization

Planned topics include legacy assessment, incremental refactoring, DDS-to-DDL conversion, application boundaries, API enablement, DevOps, observability, user-interface modernization, and AI-assisted development.

## Level 400 — Technical Leadership

Planned topics include architecture reviews, technical standards, mentoring, production-risk management, knowledge-transfer planning, technical debt, modernization roadmaps, and executive communication.
