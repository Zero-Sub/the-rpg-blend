# The RPG Blend

Craftsmanship over chaos.  
Progress without destruction.  
Calm leadership in technical spaces.

The RPG Blend is a professional body of work focused on IBM i modernization, RPG development, SQL architecture, operational discipline, AI adoption, and engineering leadership.

This repository serves as the structured source of truth for long-lived enterprise systems and the leaders responsible for them.

- Responsible IBM i Modernization
- RPG Craftsmanship and Structural Discipline
- SQL-First Architecture
- Service Boundaries and Operational Stability

The RPG Blend uses a simple operating model:

```text

GitHub Pages = public archive and library
Substack = email distribution
```

The goal is to build a durable body of work, not isolated social media posts.
