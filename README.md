# The RPG Blend

Craftsmanship over chaos.  
Progress without destruction.  
Calm leadership in technical spaces.

The RPG Blend is a professional body of work focused on IBM i modernization, RPG development, SQL architecture, operational discipline, AI adoption, engineering leadership, and structured developer education.

This repository serves as the source of truth for The RPG Blend publication and The RPG Blend Academy.

## Why This Repository Exists

IBM i systems endure because someone protects them, understands them, and prepares the next generation to support them.

This repository documents the thinking, structure, instruction, and discipline required for:

- Long-lived platform stewardship
- Technical debt management
- Predictable delivery systems
- Modernization governance
- Architecture as operational risk management
- Leadership maturity in enterprise engineering
- Developer onboarding and professional growth
